# vgrad

My very own take on [micrograd].

Made to learn the concepts in Andrej Karpathy's excellent [lecture].

Hand-rolled like the artisanal programmers of yesteryear used to do, so that I can stretch my aging
brain a little bit.

Rewritten in Rust, because of course. Almost 100% allocation-free because const evaluation is fun.

[micrograd]: https://github.com/karpathy/micrograd/
[lecture]: https://www.youtube.com/watch?v=VMj-3S1tku0
